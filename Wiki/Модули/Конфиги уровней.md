# Конфиги уровней

**Слой:** Core · **Код:** `Assets/MadSlime/Scripts/ScriptableObjects/Levels/` (+ `Levels/Data` — LevelRange, SpawnZone, SpawnShape)

Пакет ScriptableObject'ов, полностью описывающих контент уровня: что лежит на полу, где, в каких тирах, с какой квотой и на какое время.

## Зачем

Весь контент уровней — данные, не код: новые уровни = новые ассеты, редактор (`Items/Editor/ItemPropFactory` — Prop Factory) умеет их запекать.

## Состав

- **LevelConfig** — корневой конфиг уровня:
  - `Theme`: LevelTheme — материал пола + текстуры формы для сцены заливки (список `_fillShapeTextures`, `PickFillShapeTexture()` выбирает одну)
  - `PropSet`: PropSet — пропы `List<Item>` + варианты `PropVariant` (тот же префаб с другим `ItemDefinition` — другая иконка/тир)
  - `MinTier`/`MaxTier` — диапазон тиров спавна (по умолчанию Small..Huge; шкала тиров — [[PlayerTier]])
  - `TimerDuration` (по умолчанию 90 с)
  - квота: `QuotaTypesMin/Max` (1–3 типа), `QuotaTargetMin/Max` (3–8 штук), `QuotaMaxSameTier` (2 — лимит типов квоты на один тир)
- **LevelsCatalog** — `List<LevelRange>` (`Levels/Data`): «с уровня X по Y → такой LevelConfig»; выбирает [[LevelConfigResolver]]
- **LayoutsLibrary** — `List<LayoutSet>`, при генерации выбирается один
- **LayoutSet** — зоны спавна: `SpawnZone` (форма Grid/Circle/Scatter/CircleGrid/SquareRing/SquareScatter, центр, радиус, count, тир-диапазон, `SingleType` — вся зона одним предметом), `_allowMirroring`, авторасстояние (шаг = радиус крупнейшего × 2.2), `StartClearRadius` (чистая зона вокруг старта игрока), `LargeItemGap` (зазор вокруг крупных препятствий)
- **LevelTheme** — `_floorMaterial` + текстуры формы заливки (цвета текстуры проступают в призраке и конфетти)

## Связи

- **Потребляется:** [[LevelGenerator]] (раскладка через ZoneLayoutPlanner), [[Квота | QuotaGenerator]] (параметры квоты), [[FillSceneOrchestrator]] (текстура формы), [[GameplayOrchestrator]] (длительность таймера)

## Нюансы

- Диапазон тиров уровня не валидируется против содержимого PropSet при настройке — кривой ассет вскроется playable-проверкой [[LevelConfigResolver]] или при генерации (fail-fast)
- `PropSet._props` хранит `List<Item>` — ссылки на компоненты префабов: конфиг тянет MonoBehaviour вместо чистых данных (осознанно: фабрике нужен префаб)
