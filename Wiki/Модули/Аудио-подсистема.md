# Аудио-подсистема

**Слой:** Gameplay · **Код:** `Assets/MadSlime/Scripts/Audio/` — Playback (AudioPlayer, MusicChannel), Settings (AudioMixerController, AudioSettingsPanel), Events (точечные звуки), Interfaces (три шва)

Централизованный плеер + точечные звуки-подписчики. Параметры звука — `SfxClip` ([[Мелкие конфиги Core]]); музыка — `Playlist` (список треков, `RandomStart`).

## Центр

- **AudioPlayer** (root-скоуп, один класс на три шва: `IMusicPlayer` + `IGameSoundPlayer` + `IUISoundPlayer`):
  - музыка — `MusicChannel` на **двух** источниках с кроссфейдом (fade-in/out/overlap), `Play(Playlist)`
  - SFX — два пула голосов (UI и геймплей раздельно); переполнение — молчаливый дроп; перегрузки `Play(clip[, pitch][, throttle])`; `StartLoop`/`StopLoop`
- **AudioMixerController** — громкость в AudioMixer (дБ = 20·log10, guard от log(0)); пишет в сейв, перечитывает при загрузке; **AudioSettingsPanel** — слайдеры (тик SFX-слайдера с троттлингом)

## Точечные звуки (Audio/Events)

| Звук | Триггер | Особенность |
|---|---|---|
| PlayerPickupSound | `ItemCollector.ItemCollected` | случайный интервал + питч |
| TierUpSound | `PlayerTier.TierChanged` | только при реальном повышении |
| TimerTickSound | `Timer.Ticked` | луп в финальном отсчёте, старт/стоп от [[GameplayOrchestrator]] |
| FlyingCubeArrivalSound | `ShapeFiller.CubeArrived` | питч растёт с заполнением |
| FillCompleteSound | финал заливки | фанфара |
| AdrenalineSound | `AdrenalineBoost` BoostStarted/Ended | |
| UIButtonSound | `onClick` | авто-инжект скоупами ([[Скоупы сцен | SceneButtonSoundInjector]]), клип вешает дизайнер |
