# Меню (MenuOrchestrator, MenuNavigation, MenuPopupStack)

**Слой:** UI · **Код:** `Assets/MadSlime/Scripts/UI/Menu/`

Главное меню = три части: сессионный оркестратор, навигация по окнам, стек попапов. Вся мета живёт здесь: скины и улучшения — окна, рулетки — попапы; сцены Shop больше нет.

## MenuOrchestrator

FSM `Preparing → Running → Finished`. `RegisterSession` в [[SceneNavigator]]: подготовка (`MenuNavigation.Prepare` → `RoulettePreparation.Prepare` → `MenuContent.Prepare`) → `RunSession` (музыка, `Navigation.Run()`); `PlayRequested` → `ResetToPlay` + `LoadGameAsync`.

## MenuNavigation

`WindowState`: Stopped / Main / Skins / Upgrades — окна скинов и улучшений переключаются `SetActive`, превью-камера видна только в Skins.

- Кнопки: Play (`PlayRequested`), Скины (`MenuContent.RefreshSkins`), Улучшения, Лидерборд, Настройки, Ежедневный приз, закрытия окон, «Открыть скин» (скин-рулетка)
- **Попапы** через `UiSpawner.Spawn(prefab, UiLayer.Popup)`: PauseMenu (в меню — «Настройки», `Initialize(false)`), LeaderboardMenu, ежедневная рулетка, скин-рулетка, RouletteWinPopup
- `Run()`: при `SceneNavigator.TryMarkDailyShown() == true` — автопоказ ежедневной рулетки (один раз за сессию)
- Гварды: `CanInteractWithScreen` — стек попапов пуст и `IsTransitioning == false`
- Все спавны симметрично освобождаются (`Release*` снимают подписки и зовут `UiSpawner.Release`)
- Приз рулетки: `ShowPrize` → RouletteWinPopup; после закрытия — `ResumeAfterPrize` (daily) или `Hide` (skins) → `RefreshSkins(rewardSkinId)`

## MenuPopupStack

Стек открытых окон: `Push`/`Pop`/`IsOpen`/`IsTop`; каждый уровень блокирует ввод нижним (`InputState.Block/Restore`), `Clear` — при `Stop()`.
