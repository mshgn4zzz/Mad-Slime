# Рост игрока (PlayerTier, TierResolver, PlayerScaler, MassGainer)

**Слой:** Gameplay · **Код:** `Assets/MadSlime/Scripts/Player/Growth/` (+ `Items/Tiers/SizeTier.cs`, `TierLookup.cs`)

Масса и тир слайма — центральный узел событий роста. Класса Player больше нет: обработка укуса — [[Рост игрока | MassGainer]], движение — [[Движение]].

## Механика

- Тиры: `SizeTier { Small, Medium, Large, Huge, Giant, Boss }` (namespace `Skills`)
- **PlayerTier**: `Initialize()` (стартовая масса из [[PlayerConfig]]) → `Add(amount)` (≥ 0, иначе исключение): `MassChanged(prev, cur)` каждый укус; `TierChanged(prev, cur)` — **только при реальной смене тира**
- **TierResolver**: сортирует пороги PlayerConfig по RequiredMass; `GetUnlockedTier(mass)`, `GetSpeedFor(tier)`, `GetScaleFor(tier)`, `GetCameraOffsetFor(tier)`, `GetTierProgress(mass)` (доля между соседними порогами — рисует [[HUD | GrowthBarView]])
- **MassGainer** — прогресс за один укус (`ItemCollector.ItemCollected`):
  1. тир предмета == тир игрока → `ScalePunch.Punch()` (squash)
  2. `_quotaBoard.IsQuotaItem(definition)` — предмет ещё нужен по квоте ([[Квота]])
  3. `mass = max(1, round(TierMass × (квота ? GetQuotaMassMultiplier : GetMassMultiplier)))` — множители из [[PlayerUpgrades]] (квота = Appetite × Taste, обычная = Appetite)
  4. `PlayerTier.Add(mass)`
- **PlayerScaler** — применение тира к телу: `ApplyInitialScale()` (в подготовке раунда); на `TierChanged` — `GrowthAnimator.Play` (LerpUnclamped с овершутом ×1.7, 0.55 с): масштабирует модель, капсулу-коллайдер и всех `IRadiusRecipient` из списка (среди них [[Движение | Clamper]] — зона клампа растёт со слаймом), `CameraFollow.SetOffsetMultiplier` (отъезд камеры). `RelativeScaleChanged` — для эффектов ([[Эффекты игрока | SpeedSmoke]])
- **CollectAvailability** — `CanCollect(itemTier)`: можно есть не выше своего тира; перк Ambitions добавляет +1 тир ([[Детекция и сбор]])

## Связи

- Источник массы: [[Рост игрока | MassGainer]]; потребители TierChanged: PlayerScaler, [[Камера | CameraFovKickAnimator, CameraPullAnimator]], [[Эффекты игрока | TierUpFx]], TierUpSound ([[Аудио-подсистема]]), [[HUD | GrowthBarView]]; радиусы детекторов тоже масштабируются тиром ([[Детекция и сбор]])
