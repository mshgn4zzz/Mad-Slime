# Рулетки

**Слой:** UI · **Код:** `Assets/MadSlime/Scripts/Roulette/` — Runtime (RouletteModel, RouletteFactory, RouletteAccess, LootRoller, RouletteSlot, RouletteOutcome, RoulettePrize, SkinShowcase, RouletteProbabilityRules, RouletteConfigValidator, RoulettePreparation), UI (RoulettePresenter, RouletteView, RouletteWheel, RouletteWinPopup, RouletteSoundFeedback, RouletteSectorIcon)

Обе рулетки — ежедневный приз и скин-рулетка — живут в Menu и построены на одной модели: круговое колесо `RouletteWheel` (лента RouletteReel снесена). Настройка — [[Конфиги скинов и рулетки]].

## Runtime-ядро

- **RouletteModel** — безголовая рулетка: `Slots` (список `RouletteSlot`), `RefreshSlots`, `GetPrice`, `GetFreeRemainSeconds`, `GetAdSpinsLeft`, `HasAvailableSkin`, `CanSpin(adGranted)`; `Spin(adGranted, out RouletteOutcome)` — платит (через `RouletteAccess`), катит `LootRoller` по весам слотов, выдаёт приз
- **RouletteAccess** — цены/таймеры/рекламные окна делегатами (фабрика подаёт из `IRouletteStorage` + [[Wallet]]): фри-спин по кулдауну, ад-спины скользящим окном, платная крутка
- **RouletteFactory** (Scoped в Menu-скоупе) — собирает две модели из `RouletteConfig` + сейв-шва + [[Скины | SkinInventory]] + Wallet + транзакции сейва
- **LootRoller** — один ролл по весам слотов; **RouletteProbabilityRules** — правила процентов редкостей (перераспределение при пустых редкостях, исключение открытых)
- **SkinShowcase** — сохраняемая витрина скинов на колесе: `Refresh` + `CreateSlots(slotCount)`; все собраны → компенсация монетами
- **RouletteConfigValidator** — при запуске проверяет суммы процентов (100% ± 0.01), иначе `InvalidOperationException` с фактической суммой
- **RoulettePreparation** — владелец обеих моделей: `Prepare()` (в подготовке Menu-сессии), `SpawnDaily()`/`SpawnSkins()` — инстансит `RoulettePresenter`

## UI

- **RoulettePresenter** — MVP-презентер над `RouletteView` + моделью: `Show(onComplete)` / `ShowAndSpin` / `Hide` / `ResumeAfterPrize`, события `CloseRequested`/`Closed`; рефреш кнопок раз в секунду
- **RouletteWheel** — круговое колесо: idle-вращение (unscaledDeltaTime), `Spin` к предвыбранной ячейке, финал — гладкий выбег мимо ячейки (settle-swing 0.2 с) + один щелчок-возврат, win-панч
- **RouletteWinPopup** — окно приза (спавнит [[Меню | MenuNavigation]] через `UiSpawner`)
- **RouletteSoundFeedback** — щелчки/фанфары

## Выдача

`RouletteOutcome`/`RoulettePrize`: монеты → `SkinInventory`-шов + Wallet внутри сейв-транзакции; скин → `SkinInventory.Grant`; дубликат эксклюзива → компенсация монетами (из конфига). Результат пишет [[Меню | MenuNavigation]] в витрину скинов (`RefreshSkins(rewardSkinId)`).
