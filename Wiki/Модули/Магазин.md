# Магазин (окна Menu)

**Слой:** UI · **Код:** `Assets/MadSlime/Scripts/Shop/` — UI (MenuContent, SkinsPagePresenter, ShopItemView/Factory, SkinRarityGroupView, ShopBalanceView), Preview (SkinModel, ModelPlacer, PreviewRotator)

Отдельной сцены/панели магазина больше нет: улучшения и скины — окна внутри Menu ([[Меню | MenuNavigation]]: `WindowState.Skins`/`Upgrades`).

## Окна

- **Улучшения** (`MenuContent.Prepare`): грид `UpgradeEntry` (апгрейды) → разделитель перков → грид перков; покупка через [[PlayerUpgrades]] (`PurchaseStepped`/`PurchasePerk`) + [[Wallet]]
- **Все скины** (`SkinsPagePresenter`): карточки всех скинов `ShopContent`, сгруппированные по редкости (`SkinRarityGroupView`); открытые — Unlock/Select (`SkinInventory.Select` внутри сейв-транзакции), эксклюзивные — бейдж (не покупаются, только выигрыш в ежедневной рулетке); `Refresh(rewardSkinId)` — подсветка только что выбитого
- **ShopBalanceView** — баланс монет ([[Wallet | BalanceChanged]])
- **Кнопка «открыть скин»** — крутит скин-рулетку ([[Рулетки]]: `MenuNavigation.OnOpenSkinClicked` → `RoulettePreparation.SpawnSkins`)

## Превью

- **SkinModel** — модель-витрина окна скинов: слоты под скины, `RefreshSlots`
- **ModelPlacer** + **PreviewRotator** — инстанс модели скина, вращение (unscaledDeltaTime), подгон камеры по Bounds
