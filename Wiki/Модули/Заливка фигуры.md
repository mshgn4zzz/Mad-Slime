# Заливка фигуры

**Слой:** Gameplay · **Код:** `Assets/MadSlime/Scripts/ShapeFill/` — `Grid/` (GridBuilder), `Fill/` (ShapeFiller, FillResult, FillResultCalculator), `Cubes/` (CubeSpawner, FlyingCube, CubeFlightAnimator), `Input/` (FillTapButton), `Effects/` (FillCompleteAnimator), `UI/` (FillProgressUI, FillUIFabric)

Наградная мини-игра Fill: фигура уровня заливается кубиками, тапы ускоряют. Хозяин сцены — [[FillSceneOrchestrator]].

## GridBuilder — растр → сетка

Читает пиксели текстуры формы, ячейка заполнена при alpha > порога (хранит цвет); классификация бордюра (край сетки / пустые соседи → утолщение контура); FillCells сортируются **снизу вверх, слева направо** — заливка «наливается». Текстуру подменяет тема уровня ([[FillSceneOrchestrator]] → `SetShapeTexture`).

## ShapeFiller — движок

- Сессия: `Initialize` → `BuildShape` (сетка + призрак-альфа + каскад бордюра) → `ShowResult(FillResult)` (квотные кубы цветами текстуры, бонусные с тинтом `BonusTintStrength`)
- Стадии буста: Normal (спавн 0.04 с, полёт 0.5 с) → **первый тап** (`FillTapButton` → `Accelerate`) → Boosted (0.015/0.25) → **второй тап** → Instant: остаток разлетается порциями за `InstantFillDuration` 0.25 с
- `CanRescue` = результат есть, не льёмся, недолив > 0 → `Rescue()` доукомплектовывает target до полного ([[FillSceneOrchestrator | спасение за рекламу]])
- Завершение: `FillCompleted(percent)` — < 1 при недоливе, 1 при полном; `CubeArrived` — звук посадки (FlyingCubeArrivalSound)
- `FillResultCalculator` (`Construct(QuotaCounter)`) считает результат **до** показа: `FillResult(QuotaCubes, BonusCubes, TargetCubes, Percent, IsWin)` из процентов [[Квота | QuotaCounter]] прошедшего раунда — мост Game → Fill через корневой скоуп

## Кубы и финал

- **CubeSpawner**: инстанс куба на каждый спавн (без пула), цвет через MaterialPropertyBlock; **FlyingCube/CubeFlightAnimator**: полёт по Безье, stretch, качение, squash при посадке
- **FillCompleteAnimator** (100%): конфетти цветами фигуры + пунш формы (`ShapePunch*` из FillConfig) + FOV-кик; играет по `FillCompleted`
- **FillProgressUI** — полоса прогресса заливки

## Нюансы

- Кубы не пулятся: сотни инстансов на пике — главный перф-долг WebGL-сцены
- Задержки заливки масштабируемые: под рекламной паузой заливка замирает (для этой сцены — ок)
