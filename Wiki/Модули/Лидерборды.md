# Лидерборды

**Слой:** Gameplay/UI · **Код:** `Assets/MadSlime/Scripts/Leaderboards/` — Runtime (CollectedItemsCounter, LeaderboardReporter), Adapters (Yg2LeaderboardService, LeaderboardPlayerResponse, LeaderboardResponse), Data (LeaderboardData, LeaderboardEntryData), UI (LeaderboardMenu, LeaderboardRowView/Factory)

Очки = сколько предметов слайм съел за всё время. Таблица — топ-10 + строка текущего игрока.

## Запись

- **CollectedItemsCounter** (Scoped в Game): подписан на `ItemCollector.ItemCollected` → `ICollectedItemsStorage.RegisterCollectedItem()`; коммит — `CommitCollectedItems()` ([[Saver]]), его дергает [[Pauser]] при сворачивании вкладки
- **LeaderboardReporter** ([[FillSceneOrchestrator]]): `Report()` при победе/спасении — после подтверждения сейва; не авторизован — тихо ([[LeaderboardReporter]])

## Чтение

- **Yg2LeaderboardService** (`ILeaderboardService`): `SetScore`, `OpenAuthDialog`, `RequestEntriesAsync(name, topCount, ...)` с таймаутом 8 с → `LeaderboardData` (Players + CurrentPlayer + HasPlayerError); имя анонима локализует плагин
- **LeaderboardMenu** ([[Окна]]): топ-10 («вокруг 1» — своя строка), своя строка в жирном; кнопка авторизации; при ошибке — `leaderboard_error` и путь повтора, не виснет на «Загрузке»
- Авторизация — только по действию пользователя (правило платформы, [[AI_RULES]])
