# Атлас систем и геймлупа

Документ для ручного ревью: файлы перечислены в порядке исполнения — открывая их по порядку, видишь, какая система для чего нужна, где инициализируется и что кому передаёт. Код описан как есть, без оценок.

Все пути — от `Assets/MadSlime/Scripts/`, если не указано иное. Имена файлов = имена классов.

---

## 0. Карта проекта

**Геймлуп одной строкой:** Menu → Play → Game (сбор предметов → рост тиров → квота или таймер) → Fill (заливка формы кубами = процент уровня) → награда → интерстишл → Menu или повтор.

**Сборки** (`Assemblies/`): `MadSlime.Core` (данные, интерфейсы; ссылки: QuickOutline, UniTask) ← `MadSlime.Gameplay` (логика; + VContainer, Unity.InputSystem, UnityEngine.UI) ← `MadSlime.UI` (вьюхи; + TextMeshPro). Каждый листовой каталог держит `.asmref` на свою сборку.

**Папки-системы:** `DI`, `Game` (навигация сцен и сессии), `Player`, `PlayerInput`, `CameraSystem`, `Collectables`, `Items`, `Quota`, `Levels`, `ShapeFill`, `Roulette`, `Skins`, `Shop`, `Saves`, `Economy`, `Upgrades`, `Ads`, `Audio`, `Localization`, `Leaderboards`, `UI` (весь UI, подпапки по системам). Внутри системы: `Data/` (данные, SO-конфиги), `Logic/` (оркестраторы, сервисы), `View/` (визуал), `Interfaces/`, `Adapters/` (обёртки YG2), `Editor/`.

**Сцены** (`EditorBuildSettings`): 0 Menu, 1 Game, 2 Fill. Загружаются аддитивно через `SceneNavigator`, статично стартует только Menu.

## 1. Точка входа и DI

Чтение: `DI/ProjectLifetimeScope.cs` → `DI/MenuLifetimeScope.cs` → `DI/GameLifetimeScope.cs` → `DI/FillLifetimeScope.cs` → `DI/ValidatedLifetimeScope.cs` → `DI/SceneButtonSoundInjector.cs`.

- **ProjectLifetimeScope** — общий DI-контейнер. Живёт префабом `Assets/MadSlime/Resources/ProjectScope.prefab`, подключён родителем ко всем трём LifetimeScope сцен, поэтому регистрация одна на всю игру. Регистрирует: `Yg2SavesAccess` (как `ISavesAccess` + `ISavesReadiness`), `SavesCore` (как `ISavesReadiness` + `ISaveConfirmation`), все хранилища (`BalanceStorage`, `ProgressStorage` как `ILevelStorage` + `IPlayerProgressStorage`, `AudioStorage`, `CollectedItemsStorage`, `UpgradesStorage`, `SkinsStorage`, `RouletteStorage`, `LanguageStorage`), `PlayerUpgrades`, `LocalizationService`, `AudioPlayer` (как `IMusicPlayer`/`IGameSoundPlayer`/`IUISoundPlayer`), `AudioMixerController`, `SceneNavigator`, `LevelsCatalog`, `TierTable`, `LayoutsLibrary`, `QuotaBoard` + `QuotaCounter`, `LevelConfigResolver`, `Yg2AdsService` (как `IAdsService`), `Yg2LeaderboardService` (как `ILeaderboardService`), `Yg2LanguageProvider` (как `ILanguageProvider`), `Yg2GameVisibility` (как `IGameVisibility`), `Yg2GameplayReporter` (как `IGameplayReporter`). Инъекция в MonoBehaviour — методом `[Inject] Construct(...)` (канон проекта).
- **MenuLifetimeScope** — контейнер сцены Menu (первый объект иерархии). Регистрирует сценные компоненты (`MenuNavigation`, `MenuContent`, `ModelPlacer`, фабрики, `MenuOrchestrator`, `RouletteFactory` с RouletteConfig/хранилищами/`SkinInventory`/`Wallet`/`SavesTransaction`, `RoulettePreparation`, `AdScheduler`, `Wallet`, `Pauser`, `UiSpawner` с родителем `_runtimeWindows`). В `RegisterBuildCallback`: `Pauser.ResetToPlay()` (сброс паузы после перехода) и **`SceneNavigator.EnsureInitialized()` — единственная точка входа игры**.
- **GameLifetimeScope** — контейнер сцены Game: ~45 `[SerializeField]`-компонентов (игрок, камера, генератор, HUD-вьюхи). Build callback: резолв `CollectedItemsCounter` (запуск счётчика сессии), `SceneNavigator.EnsureInitialized()`, `SceneButtonSoundInjector.Inject` (звук всем `UIButtonSound` сцены).
- **FillLifetimeScope** — контейнер сцены Fill: `FillConfig`, grid-компоненты, `FillUiPresenter`, `Rewarder`, `Wallet`, `AdScheduler`, `LeaderboardReporter`, `FillSessionSaver` / `LevelThemeApplier` / `FillExitFlow`.
- **ValidatedLifetimeScope** — базовый класс всех четырёх: `ValidateAssigned` падает сразу, если поле контейнера не назначено в инспекторе.
- **SceneButtonSoundInjector** — обходит сцену, каждому `UIButtonSound` инжектит `IUISoundPlayer`. Вызывается из build callback'ов сцен.

## 2. Навигация сцен и сессии (Game)

Чтение: `Game/SceneNavigator.cs` → `Game/SceneSessionRegistry.cs` → `Game/SceneTransitionRunner.cs` → `Game/LoadingScreenController.cs` + `Game/View/LoadingScreenView.cs` → `Game/Pauser.cs` → `Game/Timer.cs`.

- **SceneNavigator** — сердце переходов. `EnsureInitialized()` определяет `SceneId` по загруженным сценам (стартовое Menu). `RegisterSession(preparation, start, finish, token)` — каждая сцена регистрирует сессию своего оркестратора в `Start()`; если идёт переход, регистрация уходит в pending. `TransitionAsync`: экран загрузки → `FinishCurrentSession` → аддитивная загрузка (`SceneTransitionRunner`, гейт активации 0.9) → ожидание pending-сессии (таймаут 10 с) → её preparation → `CompleteAsync` загрузки → выгрузка исходящей сцены (восстановление EventSystem) → promote pending → sessionStart. Публичные переходы: `LoadMenuAsync`, `LoadGameAsync` (тут же инкремент уровня через `ILevelStorage`), `ResetProgressAndLoadMenuAsync` (сброс прогресса + меню), `TryMarkDailyShown` (флаг «ежедневная рулетка уже показана сегодня», true — только первый раз за день). Передаёт preparation-progress в `LoadingScreenController`.
- **SceneSessionRegistry** — хранилище pending/current сессии. Ничего не решает, только держит.
- **SceneTransitionRunner** — механика загрузки: аддитивная загрузка сцены, отключение EventSystem/Canvas/AudioListener исходящей сцены, `SetActiveScene` на новую.
- **LoadingScreenController / LoadingScreenView** — Canvas-префаб прогресса загрузки: DOTween-заполнение полосы, иконка скина из ShopContent, `CompleteAsync` перед выгрузкой старой сцены. Спавнится навигатором.
- **Pauser** — единственный писатель `Time.timeScale`. Счётчик запросов `RequestPause`/`RequestResume` + платформенная пауза (`IAdsService.IsPauseGame`, `IGameVisibility` Hidden/Shown → `AudioListener.pause` + событие `StateChanged`; на Hidden также `_collectedItems.CommitCollectedItems()`). `ResetToPlay()` — жёсткий сброс при переходе в Game. Подписчиков через `StateChanged` будит UI и звук.
- **Timer** — игровой таймер сцены Game: `Setup(duration)` из подготовки уровня, `StartCount`/`Stop`; UniTask-цикл, тикает только при `Time.timeScale > 0`. События `Ticked(float remaining)` (подписчики: `GameplayOrchestrator`, `TimerUI`, `TimerTickSound`) и `Finished` (подписчик: `GameplayOrchestrator`).

## 3. Меню

Чтение: `UI/Menu/MenuOrchestrator.cs` → `UI/Menu/MenuNavigation.cs` → `UI/Menu/MenuPopupStack.cs` + `UI/Menu/MenuPopupInputState.cs` → `UI/Menu/MenuRouletteFlow.cs` → `UI/Shop/MenuContent.cs`.

- **MenuOrchestrator** — сессия сцены Menu. `Start()` → `SceneNavigator.RegisterSession(PrepareSessionAsync, RunSession, FinishSession)`. Prepare: `MenuNavigation.Prepare()`, `RoulettePreparation.Prepare()`, `MenuContent.Prepare()`. Run: музыка плейлиста + `MenuNavigation.Run()`. На `Navigation.PlayRequested`: `Pauser.ResetToPlay()` → `LoadGameAsync()`.
- **MenuNavigation** — роутер экранов меню: состояния Stopped/Main/Skins/Upgrades, переключение окон, кнопки Play/Skins/Upgrades/Leaderboard/Settings/Daily/OpenSkin. При `Run()` если `TryMarkDailyShown()` вернул true — открывает ежедневную рулетку. Спавнит попапы (`PauseMenu` настроек с Reset, `LeaderboardMenu`) через `UiSpawner`, ведёт стек через `MenuPopupStack`. Настройки-Reset → `ResetProgressAndLoadMenuAsync()`. Экран Skins включает preview-камеру.
- **MenuPopupStack / MenuPopupInputState** — стек попапов: блокирует CanvasGroup нижних окон и экранов, снимает блок по LIFO. `Push`/`Pop`/`Clear`/`IsTop`.
- **MenuRouletteFlow** — владеет открытыми рулетками: `OpenDaily()` (spawn из `RoulettePreparation`, приз → `RouletteWinPopup`), `OpenSkin()` (скиновая рулетка за монеты, при провале — просто `MenuContent.RefreshSkins(null)`), после закрытия приза — `ResumeAfterPrize` / `Hide`, скин-рулетка по закрытию возвращает `_rewardSkinId` в `MenuContent.RefreshSkins(id)`.
- **MenuContent** — контент меню: `Prepare()` настраивает `SkinsPagePresenter`, `UpgradesPagePresenter`, оба `ShopBalanceView`, `LevelLabelUI`. Подписки: `Localization.LanguageChanged`, `Wallet.BalanceChanged` → обновление кнопки «открыть скин» (цена из `RouletteModel.GetPrice`, доступность `CanSpin(false)`). `RefreshSkins(rewardId)` — после спина подсветить выпавший скин.

### 3.2 Страница скинов и кошелёк

Чтение: `UI/Shop/SkinsPagePresenter.cs` → `UI/Shop/ShopItemViewFactory.cs` → `UI/Shop/SkinRarityGroupView.cs` → `UI/Shop/ShopItemView.cs` → `UI/Shop/ShopBalanceView.cs`.

- **SkinsPagePresenter** — строит список скинов: группы по редкости (`SkinRarityGroupView` + цвет из `SkinRarityLookup`), внутри открытые и закрытые (`ShopItemView`). ## 4. Рулетки

Порядок данных → фабрика → модель → UI. Чтение: `Roulette/Data/RouletteConfig.cs` → `Roulette/Data/RouletteSector.cs` → `Roulette/Data/RouletteRewardType.cs` → `Roulette/Logic/RouletteProbabilityRules.cs` → `Roulette/Logic/RouletteConfigValidator.cs` → `Roulette/Logic/RouletteFactory.cs` → `Roulette/Logic/RouletteAccess.cs` → `Roulette/Logic/RouletteModel.cs` (+ `RouletteModelDependencies`, `RouletteSlot`, `RouletteOutcome`, `RoulettePrize`, `LootRoller`) → `Roulette/Logic/SkinShowcase.cs` → `Roulette/Logic/RoulettePreparation.cs`.

- **RouletteConfig** (SO) — всё о рулетках: секторы ежедневной (`RouletteSector`: монеты/скрытый скин + вес), шансы редкостей и квоты витрины скинов, цены спина (min/step/max), компенсация за дубликат, таймеры (фри-спин кулдаун, окно ад-спинов), параметры колеса (обороты, откаты, звук). Источник для валидатора, фабрики, UI-колеса.
- **RouletteConfigValidator** — fail-fast проверка конфига перед показом: сумма весов = 100%, ровно один скрытый сектор, цены/таймеры/витрина/каталог согласованы. Вызывается из `RoulettePreparation.Prepare()`.
- **RouletteFactory** (DI MenuLifetimeScope) — собирает две модели из одного конфига: `CreateDaily(slotCount)` (доступ через фри-кулдаун + ад-спины `RouletteStorage`, цена 0) и `CreateSkins(catalog, slotCount)` (доступ за монеты `Wallet`, цена растёт с `SkinSpinCount`). Отдаёт `RoulettePreparation`.
- **RouletteAccess** — функциональный адаптер доступа: делегаты `price/freeRemainSeconds/adSpinsLeft/canSpin/pay`. Фабрика подставляет разные наборы для daily/skin.
- **RouletteModel** — домен спина: `RefreshSlots` → слоты; `Spin(advertisementGranted, out RouletteOutcome)` внутри `SavesTransaction` (`ExecuteSpin`): списаться → `LootRoller.Roll` → приз → дубликат скина = монеты (`DuplicateCoinsCompensation`) → `Wallet.Add` → `RefreshShowcase`. Состояние спина атомарно с сейвом.
- **LootRoller** — взвешенный ролл по слотам.
- **SkinShowcase** — витрина скиновой рулетки: `Refresh()` держит в `RouletteStorage` набор id по квотам редкости (непрованные, не эксклюзивные, не открытые), `CreateSlots(slotCount)` — гарантия представленности всех редкостей, равномерная раскладка, веса = доля шанса редкости.
- **RoulettePreparation** (Mono, сцена Menu) — `Prepare()` (из `MenuOrchestrator`): валидация + создание обеих моделей + `RefreshSlots`. `SpawnDaily()`/`SpawnSkins()` — спавн префаба через `UiSpawner`, `RoulettePresenter.Setup(model, ads, sound, saveConfirmation)`.

### 4.1 UI рулетки

Чтение: `UI/Roulette/RoulettePresenter.cs` → `UI/Roulette/RouletteView.cs` → `UI/Roulette/RouletteWheel.cs` → `UI/Roulette/RouletteWinPopup.cs` → `UI/Roulette/RouletteSoundFeedback.cs` (+ `RouletteDisplayData`, `RouletteSectorIcon`).

- **RoulettePresenter** — FSM Hidden/Idle/WaitingForAd/ConfirmingSave/Spinning/SaveFailed. `Show`/`ShowAndSpin` (для скинов — спин сразу), кнопки обновляются раз в секунду (`RefreshButtons` → `RouletteDisplayData` → `RouletteView.Display`). Спин: `model.Spin` → подтверждение сейва (`ISaveConfirmation.ConfirmSavedAsync`) → `wheel.Spin(slotIndex)` → `Completed` → пауза `WinDwellSeconds` → приз наружу (`Action<RoulettePrize>` от `MenuRouletteFlow`). Реклама: `AdScheduler.ShowRewarded(RouletteRewardId)` → `Spin(true)`.
- **RouletteView** (IShowable) — канвас попапа: заголовок, кнопка спина/рекламы/закрытия, иконки монет по величине (пороги 150/300/1000/3000), `RouletteWinPopup` префаб наружу. События `SpinRequested`/`AdRequested`/`CloseRequested`/`Closed`/`Disabled` → презентер.
- **RouletteWheel** — само колесо: `Build(icons)` по углам слотов, `Spin(targetIndex)` — DOTween-секвенция (откат → обороты с торможением → домотка до цели с допуском `SettleMaxDeviationDegrees`), тики `Tick` на каждый сектор (→ звук), `Completed` + панч выигравшей иконки. Вне спина — idle-вращение.
- **RouletteWinPopup** (BaseWindow) — окно приза: скин (рамка/плашка/цвет по редкости, `rarity_*` ключи) или монеты. `Take` → `RequestClose`.
- **RouletteSoundFeedback** — тики колеса (троттл 0.06 с), старт спина и победа через `IUISoundPlayer`, клипы из `RouletteConfig`.

## 5. Скины

Чтение: `Skins/Data/SkinItem.cs` → `Skins/Data/SkinRarity.cs` + `SkinRarityTable.cs` + `RaritySettings.cs` + `SkinRarityLookup.cs` → `Skins/Data/SkinInventory.cs` → `Skins/Logic/SkinApplier.cs`.

- **SkinItem** (SO) — скин: id (= ключ сейва, не менять после релиза), модель-префаб, иконка, редкость. Каталог — `Shop/Data/ShopContent.cs` (`SkinItems`), эксклюзивы рулетки — список в `RouletteConfig`.

- **SkinInventory** (DI Project) — владелец инвентаря поверх `ISkinStorage`: `Initialize()` гарантирует открытый и выбранный `InitialSkinId = "Slime"`, `Grant` (для рулетки; false = дубликат), `Select`, `IsOpen`.
- **SkinApplier** (Mono, сцена Game) — инстанцирует выбранную модель в контейнер игрока: подписка `ISavesReadiness.Ready` + `Start`, подбор скина с фолбэком на начальный, событие `ModelChanged(GameObject)` (подписчик — Game-префаб игрока, например деформатор). Уничтожает старую модель.

## 6. Game: оркестратор и подготовка уровня

Чтение: `Game/GameplayOrchestrator.cs` → `Game/GameplayActivityController.cs` → `Game/GameplayPlayerSetup.cs` → `Game/FinalCountdownEffects.cs` → `Levels/Logic/LevelConfigResolver.cs` → `Levels/Data/LevelConfig.cs`.

- **GameplayOrchestrator** — FSM сессии сцены Game: `Preparing → WaitingForStart → Running → Finished`, переходы только вперёд через `TryTransitTo`. `Start()` → `RegisterSession(PrepareSessionAsync, RunSession, FinishSession)`.
  - Prepare: ввод выкл, `PlayerSetup.PrepareSession`, конфиг по `LevelConfigResolver.GetConfigFor(CurrentLevel)`, `Timer.Setup(TimerDuration)`, `LevelGenerator.GenerateAsync` (прогресс 0..0.85), `PrepareOutlineAsync` (0.85..1, обводка квоты), `QuotaCounter.ResetSession`, `RequestPause`.
  - `RunSession` (после загрузки): музыка, `QuotaCounter.Attach(collector)`, ввод вкл. Машина ждёт `MovementKeyPressed` от ввода.
  - Старт: → Running, событие `GameplayStarted` (HUD показывает игровые элементы), `Resume`, `Timer.StartCount`, `IGameplayReporter.ReportStart` (YG2).
  - `OnTimerTicked`: с `_finalSeconds` (20 с) — `FinalCountdownEffects.SetUrgency`.
  - Финиш: `Timer.Finished` или `QuotaCounter.QuotaCompleted` → FinishGame (событие `SessionFinished`, стоп активности) → 1 c реального времени → `LoadFillAsync`. `ExitToMenu` → `LoadMenuAsync`. События для UI: `SceneSessionPrepared`, `SceneSessionStarted`, `GameplayStarted`, `SessionFinished`.
- **GameplayActivityController** — гасит/будит геймплейные компоненты (детекторы, аниматор ползания, обоняние, движение, сборщик) по `SetRunning` — дергается оркестратором на паузу/финиш.
- **GameplayPlayerSetup** — подготовка игрока в Prepare: `PlayerTier.Initialize`, `PlayerScaler.ApplyInitialScale`, `Movement.Initialize`, обоняние на паузу; `PrepareOutlineAsync` делегирует `SmellAbilityActivator`; `StopSession` — камера и GrowthAnimator стоп.
- **FinalCountdownEffects** — последние 20 с: буст скорости (`Movement.SetBoostMultiplier`), виньетка, тиканье, позыв к ползанию. Читает `Timer.Ticked` через оркестратор.
- **LevelConfigResolver** — конфиг уровня по номеру: цикл по диапазонам `LevelsCatalog` (Data: `LevelsCatalog`, `LevelRange`), fail-fast если конфиг неиграбелен.
- **LevelConfig** (SO) — тема, набор пропсов, диапазон тиров, длительность таймера, параметры квоты.

### 6.1 Генерация уровня

Чтение: `Levels/Logic/LevelGenerator.cs` → `Levels/Logic/PropVariantsAssigner.cs` → `Levels/Logic/LevelPlacementPlanner.cs` → `Levels/Logic/ZoneLayoutPlanner.cs` (+ `ZonePlacement`, `LevelPlacement`) → `Levels/Logic/PlacementOccupancy.cs` → `Levels/Data/LayoutSet.cs` + `LayoutsLibrary.cs` + `SpawnZone.cs` + `SpawnShape.cs` → `Levels/Logic/LevelItemsSpawner.cs` → `Levels/Logic/LevelSurface.cs` + `LevelEnvironment.cs` → `Levels/Data/LevelTheme.cs` + `PropSet.cs` + `PropVariant.cs`.

- **LevelGenerator** — пайплайн `GenerateAsync` (вызывается оркестратором, отдаёт прогресс): резолв конфига → `PickLayout` → `PropVariantsAssigner.Assign` → план размещений → `Clamper.SetBounds` → применить тему (материал пола, `LevelSurface`, `LevelEnvironment`) → спавнер `Clear` + `SpawnAsync` (бюджет кадра ~6 мс) → `Physics.SyncTransforms` → `QuotaGenerator.Generate` → `QuotaBoard.Reset` → слои `Collectable`/`QuotaCollectable` на квотные предметы. Наружу: `SpawnedItems`, `GetFloorBounds`.
- **PropVariantsAssigner** — гарантирует в `PropSet` хотя бы один вариант на каждый тир диапазона уровня.
- **LevelPlacementPlanner** — раскладка: тиры от больших к малым × зоны, зеркалирование, пул радиусов по тиру, кап боссов (10), занятость (`PlacementOccupancy`, сетка 8 м), вычистка стартовой зоны, кламп в карту.
- **ZoneLayoutPlanner** — геометрия фигур `SpawnShape` (Grid/Circle/Scatter/CircleGrid/SquareRing/SquareScatter): расстояния, влезаемость, попытки scatter. Тот же класс (детерминированно, с сидом) переиспользует `LayoutPreviewDrawer` для гизмо.

## 8. Сбор предметов

Чтение: `Items/Data/SizeTier.cs` → `Items/Data/ItemDefinition.cs` + `TierEntry`/`TierTable`/`TierLookup` → `Collectables/Data/AttractConfig.cs` → `Collectables/Logic/OverlapRadiusDetector.cs` → `Collectables/Logic/GenericOverlapDetector.cs` → пустые наследники `ItemDetector` / `AttractableDetector` / `QuotaItemDetector` → `Collectables/Logic/ItemAttractor.cs` → `Collectables/Logic/ItemCollector.cs` → `Collectables/Logic/Absorber.cs` → `Items/Item.cs` + `ItemBody.cs` → `Items/Logic/ItemFactory.cs` → `Items/Logic/GhostToggler.cs` + `Items/View/GhostAnimator.cs` (+ `GhostFadeConfig`).

- **Item / ItemBody** — пассивные данные предмета: `Definition` (тир, иконка), `Capture` — выключение коллайдера/визуала, `ResetVisuals`.
- **ItemFactory** — Instantiate префаба + `SetDefinition` + `ItemBody.Initialize`. Используется спавнером уровня.
- **GhostToggler / GhostAnimator** — призрачный вид несобираемых предметов: `CameraObstacleDetector` (см. §9) шлёт Detected/Exited, GhostToggler решает «призрак = не по зубам», GhostAnimator меняет материал с фейдом (`_Opacity`) и подсветкой обводки (QuickOutline).

## 17. UI-инфраструктура

Чтение: `UI/Spawning/UiLayer.cs` + `IShowable.cs` + `UiSpawner.cs` → `UI/Windows/BaseWindow.cs` → `UI/Animations/ReactiveUIView.cs` + `TweenAnimatorBase.cs` + `UiFadeAnimator.cs` + `UiMoveAnimator.cs` + `UiScaleAnimator.cs` + `UiEnableTarget.cs` + `AnimationScheduler.cs` → `UI/ResponsiveUI/Runtime/ResponsiveCanvasLayout.cs` + `ResponsiveSkinGrid.cs` + `RoulettePopupLayout.cs` → `UI/Common/BarFiller.cs` + `CurrencyAmountLayout.cs` + `UniformTextSize.cs` + `WindowParticles.cs` → окна `UI/Windows/PauseMenu.cs`, `WinMenu.cs`, `FailMenu.cs`, `ResetProgressConfirmation.cs`.

- **UiSpawner** — единственный способ спавнить UI: `IObjectResolver.Instantiate` (DI работает в инстансах), родитель `_runtimeWindows`, канвасу выставляется свободный `sortingOrder` от слоя (`UiLayer`: Hud 0 / Buttons 10 / Popup 20), `Release` — deactivate + Destroy.
- **IShowable** — контракт показа с событием `Closed`. **BaseWindow** — база окон: `Show`/`BeginClose`/`RequestClose`/`Closed`; закрытие считается по завершению анимации (`ReactiveUIView.DisableCompleted`); `OnClosing` блокирует кнопки.
- **ReactiveUIView** — вьюха с аниматорами: `Enable/Disable/ResetState`, считает ожижаемые анимации, глушит CanvasGroup. **TweenAnimatorBase** — шаблон DOTween-аниматоров (fade/move/scale), SetUpdate(true) — анимации живут в паузе. **AnimationScheduler** — последовательности «действие через задержку» (реальное время) — HUD-интро, таблички квоты.
- **ResponsiveCanvasLayout** — профили портрет/ландшафт: CanvasScaler Switch (1080×1920 ↔ 1920×1080, Expand), переродитель + плейсмент + видимость элементов; применяется в Awake/OnEnable и при смене размера экрана. **ResponsiveSkinGrid** — колонки сетки скинов по ширине. **RoulettePopupLayout** — вариант попапа рулетки без контролов + центрирование одиночной кнопки.
- **Common**: **BarFiller** (fillAmount с фиксами Sliced), **CurrencyAmountLayout** (иконка+сумма по центру, ExecuteAlways), **UniformTextSize** (единый кегль группы текстов), **WindowParticles** (частицы окон в unscaled time).
- **Окна**: **PauseMenu** (закрыть/в меню/язык/сброс прогресса с подтверждением + `AudioSettingsPanel`; `Initialize(isMenuButtonNeeded, isResetAvailable)` — один префаб для гейм-паузы, настроек меню и паузы Fill), **WinMenu** (next/double/menu + count-up награды), **FailMenu** (rescue/restart/menu), **ResetProgressConfirmation** (подтверждение сброса).
