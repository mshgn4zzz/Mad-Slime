# Ошибки проекта — аудит по чек-листу «Пыточная»

**Прогон 4.** Дата: 29.10.2026 (вторая половина). Ветка codex/fill-player-emission, рабочее дерево. Область: Assets/MadSlime/Scripts (runtime + Editor), 394 файла .cs (без автогена PlayerInputActions.cs; вендор PluginYourGames, QuickOutline вне области). Проверка по `Wiki/Ревью/Требования проверки репозитория.md` (П-01..П-61), режим максимальной строгости: каждое место верифицировано чтением кода.

**Методика:** оркестратор — механический скан по всем файлам + ручная верификация каждого кандидата чтением; сабагент — архитектурно-оценочные критерии (отчёт сличён, строки перепроверены). Дополнительно прогон 4 впервые снимает **все жалобы StyleCop** (П-56/П-61-смежные правила).

**Код в этом прогоне не правился.** Все изменения рабочего дерева принадлежат владельцу. Правила StyleCop (ruleset, .editorconfig, анализаторы) не менялись — запрет владельца соблюдён; нарушения фиксировались списком, не правками.

## StyleCop: полный съём жалоб

StyleCop.Analyzers подключены через RoslynAnalyzer-DLL (`Assemblies/*/Analyzers/`: StyleCop.Analyzers.dll + проектный MadSlime.CodeStyle.dll), per-assembly ruleset'ы. Уровень **Warning — 0** (сборка `dotnet build MadSlime.UI.csproj` зелёная: 0 Warning, 0 Error). Уровень **Info скрыт в выводе MSBuild** — снят прямым запуском csc с `/errorlog` (SARIF): **107 диагностик**:

| Правило | Суть | Мест |
|---|---|---|
| SA1202 | public-члены должны идти выше private (порядок по доступам) | 86 |
| SA1204 | static-члены должны идти выше non-static | 16 |
| SA1201 | порядок видов членов (событие после свойства, ctor после свойства и т.п.) | 5 |

Соответствие чек-листу: SA1201/SA1202 — это П-56 (порядок членов), SA1204 — П-56/П-61.

**Задокументированный конфликт SA1202 ↔ П-56.** Конвенция проекта ставит Unity-методы (Awake/OnEnable/OnDisable) и `[Inject] Construct` в начало класса; SA1202 требует public-методы (Construct, публичный API) **выше** private Unity-методов. По букве П-56 (Unity-методы — отдельная группа выше обычных методов) все 86 мест чисты; по SA1202 — нарушения. Правила менять запрещено, править код в прогоне запрещено — решение о приоритете за владельцем. Полный список — Приложение Г.
