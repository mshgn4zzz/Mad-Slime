# Переходы по типам и SceneTransitor

Реализовано по согласованному обсуждению 28 октября 2026 года.

Удалены SceneId и FillExitFlow. SceneState не ограничивает TMachine через class. Exit виртуальный, OnStopped и повторный Exit из OnDisable удалены. Подписки активного состояния выполняются в Enter/Exit; подготовку Game отдельно наблюдает загрузочный presenter.

SceneStateMachine запрашивает состояние по типу и использует базовые Stop/SwitchTo для экземпляров. SceneTransitor выполняет Unity-загрузку, активацию, выгрузку и управляет временем жизни экрана. LoadingScreenPresenter выбирает скин и получает прогресс. GameStartup ожидает сохранения и инициализирует инвентарь. Авторские логи удалены из MadSlime; генерируемые и сторонние файлы сохранены.

Сценовые компоненты перемещены в GameFSM/Scenes с сохранением GUID, чтобы переходы между конкретными типами не создавали циклической зависимости сборок.

Исходные пользовательские изменения сохранены. Удалённое пользователем ResultWindowDelay ещё использовалось FillUiPresenter и ломало исходную компиляцию; задержка перенесена в сериализованное поле presenter. Pauser не перерабатывался.

Проверка: Unity 2022.3.62f2, отдельная игнорируемая копия проекта. Платформенные подмены подключены только в копии. Команда: `bash tools/verification/run-scene-transitions.sh all`.

- Контракт: 7 проверок.
- Основной игровой сценарий и жизненный цикл: 101 проверка.
- Прямой Game: 5 проверок.
- Прямой Fill: 3 проверки.
- Отсутствующая сцена: 3 проверки.
- Отсутствующая регистрация: 3 проверки.

Итого 122 проверки; все шесть процессов завершились с кодом 0. Результаты находятся в output/scene-transitor. После устранения предупреждений оформления отдельно повторена компиляция с проверкой контракта.

Итоговое ревью выполнено автором без делегирования по требованию пользователя. Коммит и публикация не выполнялись.
